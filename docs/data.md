# 数据口径

本文说明各视图中数值的计算方式。

## 时间与客户 IP

显示时间统一为北京时间。

只有在入口与终止端的指纹匹配成功时，才会填写客户 IP；匹配失败则显示“未识别”，不会以中转机地址代替。入口名称映射仅用于标明入口，不能作为客户身份的证明。

## 各视图的计算方式

| 视图 | 计算方式 |
|---|---|
| 审计明细 | 同一客户 IP、同一入口、同一网站，每 5 秒仅显示最新一条 |
| 流量汇总 | 按客户 IP、入口、网站分组，累计当月 1 日至今的流量 |
| 入口流量汇总 | 入口网卡在每个已结束分钟内的流量及平均速率 |
| 访问记录 | 已捕获的连接建立记录，不等同于网页请求次数 |
| 同步状态 | 各采集点的最后上传时间、已确认位置、延迟及缺失数量 |

## 速率与累计

- 明细中的速率：同一终止端上，该客户 IP 全部连接在过去 5 秒内的平均速率之和。该值已是整个 IP 的合计速率，同一时刻的多行不应再次相加。
- 入口网卡流量与网站流量分别统计。前者包含包头和重传，后者为实际传输的内容，二者相加没有意义。
- 流量汇总的首列格式为 `YYYY/MM/01–YYYY/MM/DD`，结束日期为最新数据的日期。月末时截止于当月最后一天，次月重新累计。
- 数据库存储原始字节数。视图中速率自动显示为 KB/s 或 MB/s，累计量按视图显示为 KB/MB 或 MB/GB，均按 1000 进位换算。
- 重复行合并仅发生在显示层，底层的连接、访问和流量记录完整保留。不同终止端各自计算的 5 秒速率，不能直接相加作为同一时刻的总速率。

## 保留期限与限制

最近 7 天的明细可直接查询，数据库内最多保留 14 天。更早的数据经校验后打包迁出数据库，迁出时将当月累计保留在库内，因此月累计始终覆盖整月。归档文件仅在明确需要时读取，不会自动导回数据库。已删除的历史数据无法恢复。

统计结果只会低于实际值，不会高于实际值。极短的连接可能未被捕获，连接断开前的最后一部分流量可能未被计入，无法识别的客户也不会计入任何人名下。因此，这些数据适用于了解使用者和大致用量，不适用于计费。存储细节见 [存储说明](storage.md)。
